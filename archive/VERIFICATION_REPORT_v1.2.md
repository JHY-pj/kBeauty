## 표본 검토
- 정상 리뷰 표본 48건: 복원 12건, 미복원 12건, 손상 없음 12건, 기간 간 제외 12건.
- 격리 표본 12건: 상품 ID 오류, 예상치 못한 열 값, 날짜·평점 손상이 복합된 사례가 포함됨.
- 주요 중복 결함: v1.2는 동일 작성자+본문 중복을 모델 입력에서 제외했지만, 다른 작성자+동일 본문 중복은 자동으로 제외하지 않음.

## v1.3 변경
- 모델 입력에 채택된 본문의 SHA-256을 M4, M5 각각 추적. 동일 본문이 재등장하면 각각 중복 삽입 방지.
- `m4_duplicate_text_excluded`, `m5_duplicate_text_excluded` 집계 추가.
- 중복 원문은 `reviews_clean.csv`에 보존.
- 작성자와 본문이 다른 경우에도 동일 문장 복제 모델 입력을 방지하는 회귀 테스트 추가.

## 주의
- v1.3으로 재실행하면 M4/M5 입력 건수가 기존보다 감소할 수 있습니다.
- 손상 복원은 규칙 기반이므로 원본과 일치했다고 단정할 수 없습니다.
- 본 샘플은 보안상 잘려 있으며 전체 원문 및 원본 행 복원 검증은 아닙니다.
- 기존 보고서와 행수 차이(+410 파싱, +1,333 유효)는 미해결.
- 원본 입력 파일의 SHA-256 값이 없는 실행 결과는 동일 파일 여부를 바이트 수준으로 확정할 수 없습니다.
